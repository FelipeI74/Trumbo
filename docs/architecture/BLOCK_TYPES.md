# Trumbo Engine
# Block Types

Los Block Types representan los elementos estructurales de un guion.

Cada Block Type existe porque tiene una utilidad real para uno o más departamentos de producción.

---

| Block Type | Descripción | Departamento |
|------------|-------------|--------------|
| HEADING | Encabezado de escena | Producción, Dirección, AD |
| ACTION | Acción narrativa | Dirección, Storyboard |
| CHARACTER | Personaje que habla | Casting, Dirección |
| DIALOGUE | Diálogo | Actores |
| PARENTHETICAL | Acotación de interpretación | Actor, Dirección |
| TRANSITION | Transición de montaje | Edición |
| SUPER | Texto sobre imagen (GC) | Postproducción, Diseño Gráfico |

## Filosofía

Un Block Type sólo existe si aporta valor al flujo de producción.

No se agregan Block Types únicamente por compatibilidad con otros programas.
